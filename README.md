# Motor HPR - Motor de Razonamiento Híbrido

Repositorio oficial para el desarrollo e implementación del Motor de Razonamiento Híbrido (HPR), diseñado para la validación determinista, el análisis de evidencias y la ejecución estructurada de tareas de IA bajo estrictos contratos de datos.

## Estructura del Proyecto
- **Contratos de Datos:** Modelos Pydantic estrictos para la gestión y validación de evidencias y afirmaciones.
- **Núcleo de Razonamiento:** Evaluadores deterministas con trazabilidad y políticas de decisión seguras.
- **Capa Conversacional:** Gestión de memoria de sesión y orquestación de tareas en lenguaje natural.
