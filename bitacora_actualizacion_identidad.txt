4. Incorporación de GestorTareasAgente (Subsistema Agéntico)
------------------------------------------------------------
- Fecha: 2026-10-04
- Ubicación: HPR/src/core/agent_task_manager.py
- Clase principal: GestorTareasAgente
- Responsabilidades:
  * Cola de tareas autónomas en segundo plano (cola_tareas)
  * Historial de ejecución completado (historial_ejecucion)
  * Procesamiento determinista de cada tarea por el ciclo de vida:
    * PENDING → RUNNING → validación via ValidadorNivelesConfianza → COMPLETED/DISCARDED
  * Integración obligatoria del ValidadorNivelesConfianza en el ciclo de procesamiento:
    - Resultado Nivel 1 (Alta Confianza / Verificado) → integrarse directamente en el flujo de salida.
    - Resultado Nivel 2 (Confianza Media / Validación Requerida) → integrarse con validación cruzada interna.
    - Resultado Nivel 3 (Baja Confianza) o información insuficiente → MARCAR COMO DESCARTADO aplicando regla estricta de cero alucinaciones: prohibido inventar datos, solicitar aclaración al usuario.
  * API pública: agregar_tarea(), procesar_siguiente(), ver_historial(), ver_estado_cola(), reiniciar().
- Dependencias: validador_niveles_confianza (inyectado en __init__).
- Casos de uso soportados: consultas web en segundo plano, procesamiento de datos determinista, tareas de enriquecimiento de conocimiento HPR con auditoría de confianza.

5. Validación de Niveles de Confianza (ValidadorNivelesConfianza)
---------------------------------------------------------------
- Clase: ValidadorNivelesConfianza
- Método: clasificar_fuente(origen, contenido, es_oficial)
- Nivel 1: es_oficial=True O "ceo_knowledge_base" en origen → "Alta Confianza (Verificado)"
- Nivel 2: contenido con ≥ 40 caracteres, no oficial → "Confianza Media (Validación Requerida)"
- Nivel 3: contenido vacío o < 40 caracteres → "Baja Confianza (Precaución)" / Descartado

6. Actualización del Agente HPR con Política de Cero Alucinaciones
-----------------------------------------------------------------
- Archivo: HPR/src/desktop/agent.py
- Integración: El agente ahora usa GestorTareasAgente para manejar consultas web externas.
- Flujo estricto:
  1. Búsqueda en bóveda interna HPR → si hay pasaje → Nivel 1 directo.

  4. Aplicación de regla de cero alucinaciones:

     - Nivel 3 / None → PROHIBIDO inventar datos. Informar transparentemente al usuario solicitando aclaración o re-consulta.
